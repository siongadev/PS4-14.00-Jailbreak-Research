# Independent native-userland route to evaluate

The public [Luac0re project](https://github.com/Gezine/Luac0re) says version 2.0 and later can execute arbitrary native **userland** code on current PS4 firmware without a kernel exploit. Its [2.4b release notes](https://github.com/Gezine/Luac0re/releases) specifically report a PS4 14.00 socket-error fix. This is the upstream project's claim, **not a result tested on this console**.

The project's stated requirements include a disc or digital copy of *Star Wars: Racer Revenge*, USA `CUSA03474` or EU `CUSA03492`. Its modified save must be resigned; the repository says existing save data cannot simply be reused. A retail console could satisfy those requirements without a devkit or testkit.

The user confirmed on 2026-10-18 that they do **not** own the required game, so this route is unavailable for the present research. No Luac0re files, save data, or payloads have been imported into this workspace. The browser candidate remains the active path.
